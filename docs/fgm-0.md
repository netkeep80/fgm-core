# FGM-0 — типизированная программа геометрии

Спецификация кандидата [C01](https://github.com/netkeep80/fgm-core/issues/5). Она задаёт абстрактную структуру программы, условия её допустимости и результат точечной выборки. Нормативная формулировка хранится в [FGMC-LANG-001](../requirements/FGMC-LANG-001.rg.yaml).

## Программа и типы

Программа содержит ровно три поля: `version` со значением `"fgm-0"`, непустой массив `nodes` и `root` с идентификатором корневого узла. Каждый узел содержит `id`, `op` и поля, перечисленные для его операции. Идентификатор соответствует выражению `[a-z][a-z0-9_]*`. Идентификаторы узлов уникальны в программе. Ссылки указывают на узлы, стоящие раньше в массиве. Корень может ссылаться на любой узел типа `field` или `matter`. Узлы, которые корень не использует, также проходят проверку.

| Тип | Значение |
| --- | --- |
| `length` | Конечное число в единицах длины модели. |
| `vec3` | Три конечных числа `[x, y, z]` в той же единице. |
| `field` | Скалярная функция точки в координатах объекта. |
| `matter` | Поле формы с одним семантическим обозначением материала. |

Единица длины модели общая для всех её узлов, точек выборки и привязанных объёмных полей. Масштаб и ориентация при размещении объекта задаются вызывающей стороной. Идентификаторы узлов, источников объёмного поля и материалов принадлежат отдельным пространствам имён.

| Операция `op` | Дополнительные поля | Результат |
| --- | --- | --- |
| `constant` | `type` со значением `length` или `vec3`, литерал `value` этого типа | Тип литерала. |
| `parameter` | `type` со значением `length` или `vec3`. Значение передаётся с именем `id`. | Тип привязанного значения. |
| `sphere` | `radius` ссылается на положительный `length` | Поле сферы с центром в начале координат. |
| `box` | `halfSize` ссылается на `vec3` с тремя положительными компонентами | Поле прямоугольного параллелепипеда с центром в начале координат. |
| `translate` | `field` ссылается на `field`, `offset` ссылается на `vec3` | Поле с переносом. |
| `union`, `intersection`, `subtract` | `left` и `right` ссылаются на `field` | Поле композиции. |
| `volume` | `source` обозначает привязанный снимок объёмного поля | Поле этого снимка. |
| `material` | `field` ссылается на `field`, `kind` обозначает семантический материал | Значение `matter` с тем же скалярным полем. |

Параметры и снимки объёмных полей привязываются явно перед выборкой. Привязки содержат только каталоги `parameters` и `volumes`. Отсутствующий каталог считается пустым. Для каждой декларации параметра нужно ровно одно значение указанного типа. Каждая ссылка `volume` должна разрешаться в снимок, задающий фиксированную скалярную функцию в общей системе единиц. Снимок, его метод выборки и привязанные значения фиксируются на всё время вычисления программы. Каталог может содержать снимки, которые программа не использует. Загрузка и форматы хранения источников относятся к [C02](https://github.com/netkeep80/fgm-core/issues/6) и [C04](https://github.com/netkeep80/fgm-core/issues/8).

Анимация, сложная физика и нейросетевые латентные поля относятся к будущим расширениям. Если внешняя система рассчитала состояние во времени или сформировала поле, в FGM-0 можно передать один зафиксированный результат как снимок объёмного поля.

## Точечная выборка

Для точки `p = [x, y, z]` используются следующие формулы. Результаты `a(p)` и `b(p)` берутся из явно указанных левого и правого полей.

| Операция | Скалярное значение |
| --- | --- |
| `sphere` | `sqrt(x² + y² + z²) − radius` |
| `box` | `max(abs(x) − hx, abs(y) − hy, abs(z) − hz)`, где `[hx, hy, hz] = halfSize` |
| `translate` | `field(p − offset)` |
| `union` | `min(a(p), b(p))` |
| `intersection` | `max(a(p), b(p))` |
| `subtract` | `max(a(p), −b(p))` |
| `volume` | Выборка привязанного снимка в точке `p`. |
| `material` | Выборка исходного поля в точке `p`. |

Отрицательный знак обозначает внутренность по полю, положительный — внешнюю область, ноль — порог. Нулевая точка сама по себе не устанавливает наличие поверхности. Например, `subtract(A, A)` даёт `abs(A(p))` и нигде не образует отрицательной области. У объединения двух соприкасающихся параллелепипедов на общей грани значение равно нулю, хотя по обе стороны грани находится материал. Правила извлечения поверхности из поля разрабатываются в [C02](https://github.com/netkeep80/fgm-core/issues/6) и [V02](https://github.com/netkeep80/fgm-renderer/issues/6). Модуль значения в общем случае отличается от евклидова расстояния до границы.

Выборка возвращает скалярное значение корневого поля и семантическое обозначение материала корня `matter`. У корня `field` обозначение отсутствует. Обозначение относится ко всему полю и не меняет его значение. Смешивание материалов, приоритеты перекрытий и способы сглаживания относятся к [C03](https://github.com/netkeep80/fgm-core/issues/7).

Входы вычисления — программа, явные привязки и координаты точки. Один экземпляр объекта использует одну программу и привязки. Соседние кубические области переводят координаты в пространство этого экземпляра. В общей точке математическое значение поля одинаково независимо от порядка выборок. Камера, уровень детализации, палитра, визуальный профиль, GPU и игровой движок отсутствуют среди входов. Правила округления и числовые допуски между реализациями определяются в [C05](https://github.com/netkeep80/fgm-core/issues/9) и [C06](https://github.com/netkeep80/fgm-core/issues/10). Согласование сеток на границе относится к рендереру. [Синтетический пример V02](https://github.com/netkeep80/fgm-renderer/issues/6#issuecomment-6868072039)

## Ошибки

Сначала проверяются поля программы, версия и структура каталогов привязок. Затем проверяются узлы в порядке массива, корень и отсутствие лишних привязок параметров. Внутри узла проверяются объявленные поля, типы, ссылки и ограничения значений. Пустой массив узлов, лишние поля и ссылки вперёд отклоняются. Ошибка проверки прерывает подготовку программы. Ошибка выборки прерывает эту выборку.

Бинарная композиция проверяет и вычисляет левый операнд перед правым. Для вычисления результата нужны оба значения. Отказ источника или нечисловое значение внутри операнда прерывает выборку, даже если другой операнд уже дал значение.

| Код | Причина |
| --- | --- |
| `E_PROGRAM` | Неверные поля программы, пустой или неверный массив узлов либо недопустимое имя корня. |
| `E_VERSION` | Неподдерживаемая версия. |
| `E_NODE` | Неверный состав полей узла или недопустимый идентификатор узла, источника или материала. |
| `E_DUPLICATE` | Повтор идентификатора узла. |
| `E_OPERATION` | Неизвестная операция. |
| `E_REFERENCE` | Недопустимое имя ссылки, ссылка на отсутствующий или последующий узел либо на отсутствующий корень. |
| `E_TYPE` | Неверный тип литерала или параметра, операнда либо корня. |
| `E_VALUE` | Неконечное или неверно заданное значение, неположительный размер либо неверная точка выборки. |
| `E_BINDINGS` | Неверная структура привязок либо поле за пределами каталогов `parameters` и `volumes`. |
| `E_PARAMETER` | Неверный каталог параметров, отсутствующий или лишний параметр. |
| `E_VOLUME` | Неверный каталог источников, отсутствующий источник объёмного поля, неверная привязка либо отказ источника при выборке. |
| `E_NUMERIC` | Промежуточная координата или вычисленное значение поля не является конечным числом. |

## Пример

В этой записи сфера радиуса 2 смещена на 3 единицы вдоль оси `x`. Для точки `[3, 0, 0]` выборка даёт `−2`, для `[5, 0, 0]` — `0`, для `[6, 0, 0]` — `1`.

~~~json
{
  "version": "fgm-0",
  "nodes": [
    {"id": "r", "op": "constant", "type": "length", "value": 2},
    {"id": "ball", "op": "sphere", "radius": "r"},
    {"id": "move", "op": "constant", "type": "vec3", "value": [3, 0, 0]},
    {"id": "shape", "op": "translate", "field": "ball", "offset": "move"}
  ],
  "root": "shape"
}
~~~

[Исполняемые примеры](../tests/fgm-0.test.mjs) используют собственные синтетические программы, точки и ожидаемые значения или коды отказа. Их исполнитель проверяет контракт C01 в CI. Каноническую сериализацию, хеши и семена определит [C04](https://github.com/netkeep80/fgm-core/issues/8), числовую модель реализации и интерфейс CPU — [C05](https://github.com/netkeep80/fgm-core/issues/9), ограничения ресурсов — [C07](https://github.com/netkeep80/fgm-core/issues/11).
